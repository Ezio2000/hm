# hm 本地编程助手管理

以真实 hm 返回结果为依据，帮助用户管理自己的编程助手。此技能提供操作流程，不包含 hm 程序或用户数据；使用 hm 前需要满足本机依赖。安装与命令见 @references/operations.md。

## 先判断执行环境

- 优先使用已连接且确认为用户目标电脑的 hm MCP。工具名可能带宿主前缀，以当前工具清单和参数定义为准。
- 无 MCP 时，仅在已确认能访问目标 macOS 的本地终端中使用 hm CLI；先检查 `command -v hm` 和 `hm --help`。缺少依赖时说明安装步骤；用户仅查询用量不意味着允许安装或迁移配置。
- 只有云端沙箱、远端 Linux、Windows 或不明来源环境时，不安装 hm 来冒充本机访问。改为给用户本机命令，请其提供必要的汇总结果，不索要原始会话或认证文件。
- 发现版本差异时按当前 help 或 MCP schema 调整；不存在的功能不要虚构。

## 按任务选择最小范围

1. **查看实例与能力**：用 `overview` 或 `hm instances --json`。清单反映已配置内容，不证明服务在线、登录有效或有剩余额度。
2. **用量、费用与速度**：用 `usage_report` 或 CLI `usage`、`speed`，优先按用户指定实例与时间过滤；未指定时近 7 天、按实例与模型汇总。除非用户需要，不按 session 展开，以免暴露项目标识。
3. **额度与余额**：用 `read_quota` 或 `hm quota`，只查询目标实例。此操作会由本机 hm 使用已有凭据访问相应提供商，不是纯离线统计。不要为此调用明文凭据读取接口。
4. **配置诊断**：用 `overview`、`check_status` 查看结构与状态，先解释实例层与共享层的作用，再给针对性操作建议。不要把一次接口失败解释为账号封禁。
5. **初始化、实例管理、插件、Skill、MCP 和提示词调整**：执行前明确目标和影响范围；已有具体授权不重复索取。普通非敏感操作可使用实际提供的工具；有敏感配置读写、账号登录或凭据输入时让用户在本机 `hm` 界面完成。没有足够信息时不执行全量覆盖写入。

## 敏感数据与修改边界

- `read_credentials` 会返回完整密钥或 OAuth token；`read_layer`、`read_result` 也可能返回凭据、私有提示词和 MCP 环境变量。此公开技能不调用这三个接口，也不通过 shell 读取认证文件、Keychain 或整份配置来绕过这一限制。
- 不要求用户粘贴 API Key、Cookie、验证码、认证文件或完整会话。意外发现秘密时不复述、不保存到报告；提示用户采取必要的凭据处置。
- 实例名、提供商地址、模型名、项目标识和用量也可能是私人信息。仅返回完成任务所需字段；共享报告前按用户指定范围匿名化。不要声称“只读”即意味着没有数据传输。
- 技能不能阻止宿主把工具输出发送给模型服务。不能接受这类数据处理的用户应在本机终端自行查看结果，不向聊天提供原始输出。
- `save_settings`、`save_mcp`、`save_prompt` 是替换操作；不基于空白或不完整内容覆盖原数据。需要读取敏感现状才能安全修改时，指导用户在本机 UI 操作。
- 修改共享层会影响相应客户端的多个实例。删除实例涉及本地数据，不能当成普通重启或清缓存；执行前遵循宿主的删除确认机制。备份放在本机，不上传。
- 不将账号共享、凭据分发、绕过访问控制或规避供应商计费作为功能。只操作用户拥有或已获授权的环境。

## 报告结果

- 费用来自本地定价表，属于美元估算，不等于提供商账单；价格缺失显示不可估算，不能当作零费用。
- 速度来自历史日志时间戳，不是实时压测；无有效计时数据时明确缺失，不把空值当零速度。
- 区分配置存在、登录状态、接口成功和可用额度。剩余比例与已用比例不能混淆；重置时间按用户时区显示。
- 总结实际查询范围、结果与限制。做过修改时报告目标、变更及验证；未执行或无法访问时明确说明，不把操作指导写成完成结果。
